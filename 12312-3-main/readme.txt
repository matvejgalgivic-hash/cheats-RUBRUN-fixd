============================================================
  armore3 - client build (123.exe) + loader
  readme: how to run / как запустить
============================================================

ЧТО ЭТО
-------
Пропатченный клиент чита (123.exe) и launcher start.bat.
Всё, что нужно для запуска, уже лежит в этой папке.
Патч применяется автоматически при каждом запуске start.bat.

ЧТО В СБОРКЕ (патч armore3)
---------------------------
* Водяной знак в меню: BY armore3
* END - полная выгрузка чита (клиент + оверлей), БЕЗ Ctrl
* Акцентных пресетов: 10 (было 6)
* ESP и aim assist автоматически пропускают своих (team) и клан (clan)
* настройки аима сохраняются между запусками (watchdog)

ТРЕБОВАНИЯ
----------
* Windows 10/11 x64
* права администратора (start.bat сам запросит UAC)
* на Windows 11 может понадобиться отключить Vulnerable Driver Blocklist
  (см. раздел "Если драйвер не поднимается")

ФАЙЛЫ РЯДОМ
-----------
  start.bat        launcher: патчит клиент, ставит драйвер, запускает чит
  123.exe          клиент чита (пропатченный)
  123.exe.stock    чистая копия - база для патча (запускать НЕ надо)
  driver.bin       драйвер для маппинга
  123.sys          драйвер Intel (Nal)
  mapper.exe       лоадер драйвера
  run\             рабочая папка (start.bat запускает run\123.exe)
  tools\123.ps1    движок стадирования

ЗАПУСК
------
1. Закрой игру и чит, если что-то из этого уже запущено.
2. Запусти start.bat двойным кликом. Он сам попросит права администратора.
   (либо: правый клик -> "Запуск от имени администратора")
3. В консоли дождись строк:

     [armore3] patched 123.exe  sha256 ...
     [*] stage...
     [+] ok
     [*] client...
     [+] end

   После этого чит запущен - появится меню/оверлей.

ВЫХОД
-----
* END - полностью закрывает чит (клиент + оверлей). Ctrl не нужен.
* Драйвер в ядре остаётся до перезагрузки (он маппится в пул ядра).
  Для полностью чистого состояния ядра - перезагрузка Windows.

ПОЛЕЗНЫЕ ФЛАГИ start.bat
------------------------
  start.bat            обычный запуск (патч + драйвер + клиент)
  start.bat --s        дополнительные проверки состояния
  start.bat --u        полный режим (есть риск bugcheck)
  start.bat --i        патч Intel-драйвера
  start.bat --n        только драйвер, клиент не запускать
  start.bat --b        отключить driver blocklist (нужна перезагрузка)
  start.bat --loot     запустить сборку с FastLoot (Loader\RobRun.exe)
  start.bat --aim      починить настройки аима в %APPDATA%\focus_robrun.cfg
  start.bat --r        restore: вернуть исходный 123.exe и драйверы

НАСТРОЙКИ АИМА
--------------
  %APPDATA%\focus_robrun.cfg                  текущие настройки (клиент их перезаписывает)
  %APPDATA%\focus_robrun.aim                  снимок настроек; возвращается при каждом запуске
  %APPDATA%\focus_robrun.cfg.before_armore3   бэкап до правок

ВЫГРУЗКА (если END не сработал)
--------------------------------
* заверши 123.exe через диспетчер задач, либо
* аварийно создай файл-стоп:  %TEMP%\focus_robrun.stop
  клиент увидит его и корректно завершится сам.

ЕСЛИ ДРАЙВЕР НЕ ПОДНИМАЕТСЯ
---------------------------
Если в логе видишь:

    [warn] blocklist on: 0x1

то один раз отключи блок-лист драйверов и перезагрузись:

    start.bat --b

после перезагрузки запусти start.bat снова.

Если в логе "timeout" (нет %TEMP%\focus.key) - драйвер не стартовал:
проверь права администратора и blocklist (--b + ребут).

ОБНОВЛЕНИЕ КЛИЕНТА
------------------
Положи новую чистую сборку как 123.exe.stock и запусти start.bat заново -
патчер найдёт все места заново.
Если появилось "NEW BUILD ... left untouched" - сборка новая, патч под неё
ещё не обновлён.

ЧАСТЫЕ ВОПРОСЫ
--------------
* "missing: tools\123.ps1" - запускай start.bat из папки проекта, файл
  tools\123.ps1 должен быть на месте.
* SmartScreen/антивирус ругается - разреши запуск (Windows защищает
  неизвестные .bat/.exe).
* Клиент запускается, но END не реагирует - убедись, что запущен именно
  патченный run\123.exe (start.bat кладёт его туда сам).
